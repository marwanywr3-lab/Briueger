## النشر المباشر على GitHub Pages
1. ارفع محتويات هذا الأرشيف مباشرة إلى مستودع GitHub جديد (تأكد أن `index.html` في المجلد الرئيسي).
2. انتقل إلى **Settings → Pages**.
3. اختر الفرع **main** والمجلد **/ (root)** ثم اضغط **Save**.
4. خلال دقيقة سيعمل الموقع مباشرة على رابط GitHub Pages الخاص بك.
